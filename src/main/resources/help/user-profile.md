**User Profile** lets you update your display name and planning color. It is
not the administration page for changing users' roles or identity providers.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Update your profile

![Display name](images/help/light/UserProfileView/user-name-field.png)

Enter a non-empty name. This is the application display name, not a request to
rename the account at your external identity provider.

![Email](images/help/light/UserProfileView/user-email-field.png)

Email is read-only here. The profile form does not change your sign-in identity.

![Planning color](images/help/light/UserProfileView/user-color-picker.png)

Choose a User Color used to distinguish you in planning displays. It is not
the application's light/dark theme preference.

![Save changes](images/help/light/UserProfileView/save-profile-button.png)

Use **Save Changes** to persist your edits. Opening help does not save or
discard them. Navigating away can lose unsaved input; this page has no separate
Cancel button. Profile changes are not covered by planning undo/redo.

## Understand optional images and working time

When Stable Diffusion is available, a magic-wand action beside the name opens
the optional avatar workflow. It is not required to save a name or color.
Image generation and accepting a generated result are separate from ordinary
profile fields; inspect notifications before assuming every part was saved.

The profile does not edit effective-dated capacity or absence records.
Use the account menu's **Manage Availability**, **Manage Location**,
**Manage Off Days** and **Manage Work Week** for those settings.
