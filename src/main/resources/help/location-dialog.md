Set the country and region used for a user's holiday calendar from a particular
date. This is a planning location, not a task assignment.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Choose the applicable holiday region

![Country](images/help/light/LocationDialog/location-country-field.png)

![State or region](images/help/light/LocationDialog/location-state-field.png)

Country and State/Region are required. Choose the country first: its selection
determines the available regions. After changing country, check the region
again rather than assuming the previous one still applies.

The location determines regional public holidays in the user's calendar.
Use **Off Days** for personal absences; changing location does not record a
vacation.

## Date the change instead of rewriting history

![Effective start date](images/help/light/LocationDialog/location-start-date-field.png)

The required start date must be unique among this user's location records.
Create a dated record for a move; edit an existing record to correct it.
The most recent applicable location supplies the holiday region until the
next dated location takes over.

## Save for the intended user

![Save location](images/help/light/LocationDialog/location-dialog-confirm.png)

![Cancel location changes](images/help/light/LocationDialog/location-dialog-cancel.png)

**Save** applies the location to the user whose page opened this form,
refreshes that page and closes the dialog. Correct missing selections or a
duplicate date before retrying.

**Cancel** discards unsaved input. Location administration is not part of
planning undo/redo; check existing records after a reported save failure.
