**Work Weeks** defines reusable weekly schedules. Administrators maintain the
definitions here; users receive them through effective-dated **User Work Week**
assignments. Creating a definition does not assign it to anyone.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Create or change a definition

![Create work week](images/help/light/WorkWeekListView/create-work-week-button.png)

Create a clearly named schedule with the required working-day/time information,
then Save. Cancel discards unsaved changes.

![Edit work week](images/help/light/WorkWeekListView/work-week-edit-button-.png)

Edit changes the **shared definition**, affecting its users. For a schedule
change that applies to one person from a future date, use a different definition
and a dated User Work Week assignment instead of rewriting the shared schedule.

## Remove an unused definition

![Delete work week](images/help/light/WorkWeekListView/work-week-delete-button-.png)

A definition with user assignments cannot be deleted. The page explains this
restriction rather than deleting its users' schedules. Reassign or remove
references first, while retaining the required assignment for each user.

For an unused definition, check the delete confirmation before proceeding.
Work-week administration is not covered by planning undo/redo.
