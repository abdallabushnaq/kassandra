**Off Days** records dated absences for a user. Use it for time away rather
than changing a reusable work-week definition or deleting task assignments.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Find absences in the right year

![Previous year](images/help/light/OffDayListView/calendar-prev-year-btn.png)

![Next year](images/help/light/OffDayListView/calendar-next-year-btn.png)

The table contains absences **overlapping the calendar's selected year**,
including ranges that cross a year boundary. Change the year before concluding
that an absence is missing.

## Create, edit or remove an absence

![Create absence](images/help/light/OffDayListView/create-offday-button.png)

Use Create, enter the first and last day and the appropriate type, then Save.
Check the user and the full date range before saving. Cancel discards unsaved
form changes.

![Edit absence](images/help/light/OffDayListView/offday-edit-button-.png)

Edit corrects an existing absence rather than adding a second copy.

![Delete absence](images/help/light/OffDayListView/offday-delete-button-.png)

Delete removes the absence after confirmation and can make that time available
for planning again. It does not delete the user's tasks. Off-day changes are
not replayed through planning undo/redo.

## Interpret calendar colors

![Vacation](images/help/light/OffDayListView/calendar-legend-item-vacation.png)

![Sick leave](images/help/light/OffDayListView/calendar-legend-item-sick-leave.png)

![Public holidays](images/help/light/OffDayListView/calendar-legend-item-holiday.png)

![Business trips](images/help/light/OffDayListView/calendar-legend-item-business-trip.png)

The legend distinguishes absence types and public holidays. Regional holidays
also depend on Location; changing a personal absence does not change the
regional holiday rules. Clicking a day with a recorded absence lets you inspect
the corresponding record.
