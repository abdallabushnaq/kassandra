Assign an existing weekly schedule to a user from a particular date. This
changes the user's assignment, not the shared schedule definition.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Choose the right reusable schedule

![Work-week selection](images/help/light/UserWorkWeekDialog/user-work-week-combo-field.png)

Select a required **Work Week** from the existing definitions. Its working
days and times determine the user's regular timetable. If no suitable
definition exists, an administrator must create one in **Manage Work Weeks**.

For a change affecting only this user, assign a different definition instead
of editing a definition shared by other users.

## Choose when the new timetable starts

![Effective start date](images/help/light/UserWorkWeekDialog/user-work-week-start-date-field.png)

The required start date must not duplicate another assignment for this user.
The selected definition applies from that date until a later assignment
takes over. Create a new dated assignment for a schedule change; edit an
existing assignment to correct its date or definition.

Absences, regional holidays and availability are separate inputs. Assigning
a work week does not remove them.

## Save the assignment

![Save assignment](images/help/light/UserWorkWeekDialog/user-work-week-dialog-confirm.png)

![Cancel assignment changes](images/help/light/UserWorkWeekDialog/user-work-week-dialog-cancel.png)

**Save** applies the assignment for the user whose page opened the form,
refreshes the page and closes the dialog. Check the selected user and date
before saving.

Correct missing values or a duplicate-date error before retrying. **Cancel**
discards unsaved input. Work-week assignments are not covered by planning
undo/redo.
