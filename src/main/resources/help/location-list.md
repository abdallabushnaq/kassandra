**Location** records a user's country and region over time. These determine
which regional public holidays apply to the working calendar; they do not
assign the user to a product.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Find location records

The account menu opens your location history. Check the user context when
managing someone else's records.

## Record or correct a location

![Create location](images/help/light/LocationListView/create-location-button.png)

Use Create for a location that begins on a new effective date. Select the
country and region offered by the form, then Save. A later record determines
the location from its start date; it does not erase earlier location history.

![Edit location](images/help/light/LocationListView/location-edit-button-.png)

Edit corrects an existing date, country or region. Save applies the correction;
Cancel leaves the saved record unchanged. Changing a region can change the
public holidays used for scheduling.

![Delete location](images/help/light/LocationListView/location-delete-button-.png)

Delete removes the record after confirmation, which can make an earlier
location apply for longer. A user must retain at least one location, so the
last record cannot be deleted. Planning history does not undo location changes.

## Inspect the working calendar

![Previous year](images/help/light/LocationListView/calendar-prev-year-btn.png)

![Next year](images/help/light/LocationListView/calendar-next-year-btn.png)

Move between years to inspect the working calendar. The location table keeps
the user's location history regardless of the selected calendar year.

![Public holiday legend](images/help/light/LocationListView/calendar-legend-item-holiday.png)

![Vacation legend](images/help/light/LocationListView/calendar-legend-item-vacation.png)

Calendar colors distinguish holidays and absences. The calendar is not a list
of location records. Check the effective region and the server's holiday
coverage if expected holidays are absent; record personal absences in Off Days.
