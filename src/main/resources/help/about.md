**About** identifies this Kassandra installation and links to its licence and
source project. Opening it does not change your planning data.

Open a chapter for the task you need. **Expand all** opens every chapter;
**Collapse all** returns to the overview.

## Identify the application

![Application heading](images/help/light/AboutView/about-page-title.png)

The application name and **Version** identify the software running on this
server. Include the displayed version when reporting a problem.

The optional banner is loaded in the background and follows the current theme.
It is not project data; the version and links remain useful without a generated
image. A missing banner does not mean your products are missing.

## Find the licence and source

![Licence link](images/help/light/AboutView/about-license-link.png)

**Apache License 2.0** opens the licence in a separate browser tab.

![Source repository link](images/help/light/AboutView/about-github-link.png)

**GitHub** opens the Kassandra source repository. These are external links;
neither link saves or exports your server's planning data.
